这是一个 **B 站弹幕机器人 + 积分商城系统** 的完整解决方案。
支持自动欢迎观众、答谢礼物、播报关注与分享等常用直播功能，并内置可自定义的积分机制：观众通过上舰、签到等方式积累积分，可在商城兑换虚拟道具或实体奖品。

项目提供 **两个不同的版本**，真正做到开箱即用，让你的直播间更有互动性、更自动化，也更好玩。

## 两个版本

推荐使用 **Go 重构版**。它是用 Go 完全重写的版本，可以看作是 PHP 版的全方面升级：性能更好、部署更省事，既能本地双击运行，也能部署到服务器对外提供服务。

原有的 **PHP 服务器版**依然保留并继续维护，主要是为了方便已经有 PHP 环境、或者更习惯 PHP 那套部署方式的朋友。它功能上够用，但不再是主要推荐。

|          | Go 重构版（推荐）                    | PHP 服务器版                |
| -------- | ------------------------------------ | --------------------------- |
| 技术栈   | Go，编译为单个可执行文件             | PHP + MySQL + Redis         |
| 环境要求 | 无，下载即用                         | 需要 Docker 或宝塔面板      |
| 运行方式 | 本地双击运行，也可部署到服务器       | 部署在服务器上              |
| 数据存放 | 默认在你自己的电脑                   | 在你的服务器                |
| 默认访问 | 本机 `localhost`，放到服务器即可对外 | 服务器 IP 或域名            |
| 定位     | 主要维护版本，持续迭代               | 保留维护，适合已有 PHP 环境 |

- **Go 重构版**：单文件分发，下载解压双击就能用；同一份包放到服务器上运行就能对外提供服务，不需要自己构建
- **PHP 服务器版**：部署和配置对熟悉 PHP 的朋友更顺手，如果你本来就有 PHP 环境，用这个版本会更省事

## 功能特色

- **积分商城**

  观众可通过每日签到、开通大航海、赠送礼物等方式获取积分，并用于兑换虚拟道具或实体礼品。支持后台管理、上下架商品、积分变更记录等。

- **直播间打卡签到**

  观众每天可签到获取积分，并记录累计/连续签到天数，让直播间形成健康的活跃循环。

- **PK 播报**

  PK 对战开启前，自动播报对手的活跃数据和贡献榜信息，支持自定义播报模板，让直播节奏更带感。

- **礼物答谢**

  收到礼物后自动播报感谢语，可设置金额门槛并自定义多条个性化文案随机展示。

- **定时广告**

  定时推送预设内容，支持多条文案随机发送，用于宣传加群、抽奖、活动、商单等。

- **进房欢迎**

  观众进入直播间时自动欢迎，支持多套话术随机展示，提升互动体验。

- **感谢关注**

  当用户关注直播间时自动感谢，并支持多条话术。

- **感谢分享**

  用户分享直播间时自动感谢，支持多条文案的随机展示。

- **自动回复**

  当弹幕触发预设关键词时自动回复，支持自定义多套回复方案，并随机输出，让机器人更自然不生硬。

- **自动禁言**

  与自动回复联动，对违规触发内容的观众进行临时禁言；并支持通过赠送指定金额的礼物自动解除禁言。

- **数据分析**

  记录直播间弹幕与礼物信息，生成用户每日消费统计、盲盒盈亏数据、弹幕词云等分析报告，帮助主播了解观众互动和贡献情况，更好地优化直播策略。
